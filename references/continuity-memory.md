# 连续性记忆与资产结构

多集 / 多镜头内容的地基。**身份板回答「长什么样」，本文档回答「现在是什么状态」——两者不能互相替代。**

---

## 一、角色资产

**核心原则：角色层整段逐字冻结，只读不改。** 不得把外貌与服装描述拆成 `{发色}` `{瞳色}` 这类变量槽位 —— 每次填充措辞不同必然导致漂移。

## 二、场景资产

```json
{
  "scene_id": "loca_001",
  "name": "公寓楼公共客厅",
  "space_type": "室内 · 合租公寓公共区域",
  "lighting": "午后侧窗自然光，光源自画面左侧，柔和无硬阴影",
  "atmosphere_color": "暖木色为主，墙面浅灰",
  "fixtures": ["长沙发", "圆餐桌", "六把椅子", "门", "窗"],
  "主锚": "圆餐桌（所有角色的位置以它为参照）",
  "linked_props": ["prop_001"]
}
```

**场景锁定要点**：主锚与固定地标、主要物体的相对位置、光源方向、主色调、可移动道具的初始位置、入场与离场路径、可能影响视线的空间关系。

## 三、道具资产

```json
{
  "prop_id": "prop_001",
  "name": "装着零食的小纸袋",
  "appearance": "牛皮纸小袋，袋口微微张开，被攥出折痕",
  "function": "关系道具 —— 想给出去但没给出去",

```

道具在多镜头内容里最容易穿帮。**它的出现、拿起、移动、放下必须连续。**

## 四、连续性记忆（每个场景 / 每个片段一份）

```markdown
# 连续性记忆 · [场景名] · [片段编号]

## 时间与场景状态
- 时间点：
- 场景已被改变的部分（谁动过什么）：

## 在场角色状态表

| 角色 | 位置（相对主锚） | 面向 | 身体状态 | 手持物 | 情绪 |
|---|---|---|---|---|---|
| 皮皮 | 桌子主位左侧 | 朝向全桌 | 站立，脊柱直立 | 茶壶 | 平视不笑 |
| 露娜 | 门口内侧 | 身体朝门，视线朝 koko | 抱臂 | 无 | 面无表情 |
| … | | | | | |

## 本片段不出现的角色
- [逐个列出]

## 核心道具状态
- 

## 起始快照（start_state）
[所有在场角色的位置、面向、表情与身体状态、道具状态、场景状态]

## 目标末态（end_state）
[本片段结束时**可被下一段承接**的状态]

## 承接规则
上一段的 end_state 必须等于下一段的 start_state。
```

**注意**：`起始快照` 不能引用本片段自己的 `end_state`（循环依赖）。它必须来自项目初始状态或上一个片段的 `end_state`。

## 五、ID 规范与复用

| 类型 | 前缀 | 示例 |
|---|---|---|
| 角色 | `cat_` | cat_001, cat_002 |
| 场景 | `loca_` | loca_001 |
| 道具 | `prop_` | prop_001 |

**跨集复用**：续集生成时传入已有资产 ID，自动加载原设定 —— 外貌与服装保持一致、场景光影继承、道具外观统一。这是「同一角色第二套设定」这类复购需求的技术底座。

**增量迭代**：新增角色 / 场景 / 道具按序号继续递增，并更新资产索引。

## 六、常见漂移成因（排查用）

| 现象 | 常见成因 |
|---|---|
| 改了 A 却连带改了 B | 未列「保持不变」清单；参考图未声明职责 |
| 同一角色这次和上次不像 | 设计指纹被改写；未携带锚点图作参考 |
| 群像缺人 | 未点名全员；未声明未入场角色「不出现」 |
| 尾巴形状变来变去 | 未查个体特征表；凭品种印象写形状词 |
| 视频里局部被重画 | 单片段动作超过两个；未锁镜头；未禁重绘 |
| 角色比例忽大忽小 | 试图在单张里求身高 —— 应改用程序化校准合影 |
